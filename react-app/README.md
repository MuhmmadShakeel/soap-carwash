# SOAP Hand Car Wash

A responsive React and Tailwind redesign built from the supplied SOAP Hand Car Wash content and original image library.

## Run locally

```bash
npm install
npm run dev
```

Create a production bundle with:

```bash
npm run build
```

## Structure

- `src/App.jsx` — page sections and interactions
- `src/components/` — navbar, footer, headings and local SVG icons
- `src/data/siteData.js` — services, locations, FAQs, posts and gallery data
- `src/styles/index.css` — Tailwind layers, responsive design and both color schemes
- `public/images/` — untouched supplied SOAP images

Use the **Night wash / Ocean blue** button in the navbar to switch between the two persistent color schemes.
